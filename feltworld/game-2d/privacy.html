Shared preview · draft policies

Feltworld is the project name. The proposed company Feltworld Ltd has not been incorporated. The current legal operator’s full name and service address still need to be confirmed before public release. These pages do not represent an existing registered limited company.

Privacy notice

The game has no account, analytics, advertising, contact form or social-media tracking. It does not ask for your name, age, location or other profile information.

What stays in your browser

Your chosen actions, collected glimmers, saved progress and selected settings are stored locally when remembering is enabled. The saved records are not uploaded as game-save data. There is no cloud sync. See Cookies & storage for the exact storage keys and controls.

Technical requests and logs

This shared preview is hosted by GitHub Pages. Your browser requests the game’s pages, artwork, scripts and fonts from GitHub. GitHub states that it logs and stores visitors’ IP addresses for security purposes, whether or not they are signed in. See GitHub Pages: data collection and the GitHub Privacy Statement for GitHub’s processing practices.

Game saves and settings remain in your browser. The project does not collect them or run its own server logs, analytics or advertising. The operator details and the remaining draft policy information still need to be completed for a full public launch.

If you email us

An email you send to email@feltworld.uk will include your email address and whatever you choose to write. The intended use is to answer your enquiry. The actual legal controller, email provider and retention arrangements must be confirmed before this contact service is used for a public launch. Please do not send sensitive personal information about yourself or children.

Your controls and rights

You can switch off remembering in Storage settings and remove the game’s local data using your browser’s site-data controls. If an operator processes personal data about you, UK data-protection rights may include access, correction, deletion, restriction and objection; which rights apply depends on that processing. You may raise a concern with the Information Commissioner’s Office.

Children

The game is fictional and suitable for shared play. It has no chat, public profiles, targeted advertising or profiling. If it is later launched as a public service likely to be accessed by children, the operator must assess the relevant ICO children’s-code requirements for that service before launch.
